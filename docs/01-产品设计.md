# S1 Goose 产品设计文档

> Stage1st 论坛原生 iOS 客户端。功能对齐 Android 端 S1-Next,交互与视觉遵循 Apple Human Interface Guidelines。
> 参考项目:`/Volumes/UsbDrive/Dev/S1-Next`(Android)。本文档为其 iOS 重设计的唯一产品依据。

## 1. 产品概述

| 项 | 值 |
|---|---|
| App 名称 | S1 Goose |
| Bundle ID | `com.bitxeno.s1goose` |
| 平台 | iOS 17.0+,Universal(iPhone 优先,iPad 兼容运行) |
| 技术底座 | UIKit + SQLiteData(Point-Free,GRDB)+ SnapKit + SwiftSoup + Kingfisher |
| 目标论坛 | Stage1st(https://stage1st.com/2b/,Discuz! X) |
| 语言 | 界面文案简体中文(zh-CN) |

### 设计原则
1. **原生优先**:帖子内容不用 WebView,全部原生渲染;系统导航/手势/无障碍全量保留。
2. **HIG 对齐**:侧边抽屉改为 Tab Bar;语义色 + 跟随系统深色模式;Dynamic Type;44pt 触控目标。
3. **对齐 S1-Next 功能**:以 S1-Next 功能集为基准,分期补齐(见 §2)。
4. **克制**:不移植 9 套主题引擎,跟随系统 + 单一 accent;减少设置项噪音。

## 4. 页面规格

### 4.1 ForumGroupsViewController(版块组)
- **布局**:`UITableView`(insetGrouped)。每个版块分组(category)= 一个 Section,header 为分组名;行 = 版块(名称 + 帖子数/今日帖数 secondary 文本)。置顶公告类版块跟随服务端顺序。
- **数据**:`forumindex` API,一次全量;无分页。
- **状态**:下拉刷新;加载失败整页错误视图(重试);离线不缓存(M1)。
- **交互**:点击行 → push ThreadList;长按 → 「在 Safari 打开」(M3)。
- **HIG**:cell 高度 ≥44pt;空心分组头用 `.header` 字体;支持 Dynamic Type。

### 4.2 ThreadListViewController(主题列表)
- **布局**:`UICollectionView` + CompositionalLayout(list) + DiffableDataSource,自尺寸 cell。
- **Cell 内容**:标题(`.headline`,已读主题降为 `.subheadline` + secondary 色——依据本地历史/进度);作者与发帖时间(`.footnote`);右侧回帖数/浏览数、最后回复时间;图标角标:置顶📌、附件📎、投票、精华(服务端字段)。「新增 N 回复」徽标(M3,需 DbThread 快照)。
- **分页**:滚动到底自动请求下一页(游标追加,每页 50);顶部下拉刷新回到第 1 页;导航栏「跳页」菜单输入页码。
- **工具栏**:导航栏 trailing:`发新帖`(M2 禁用态)+「更多」菜单(禁用置顶显示/M3)。
- **黑名单过滤**:`forumLevel=删除` 的用户主题直接不展示;`隐藏` 的显示占位 cell「已屏蔽主题(备注)」。
- **状态**:首屏 loading;上拉加载 footer(spinner/没有更多);错误 banner + 重试;空态(该版块暂无主题)。

### 4.3 PostListViewController(帖子详情)— 核心
- **布局**:`UICollectionView` + CompositionalLayout + DiffableDataSource。**每个楼层 = 一个 Section**:header=楼层头,内容块=多个 item,footer=楼层操作条。
- **楼层头 item**:头像(圆形,48pt,Kingfisher)+ 用户名(`.subheadline` semibold)+ 时间/楼层号(`.footnote` secondary)。点头像 → UserHome(M2)。
- **内容块 item 类型**(自上而下由渲染管线产出):
  | 块 | 呈现 |
  |---|---|
  | text | UITextView(禁滚动)/ UILabel + NSAttributedString,内联表情为文本附件,链接可点 |
  | image | 独立图片 cell,按原图比例自适应,最大高度约束,点击进画廊 |
  | quote | 引用块:左侧 3pt accent 竖线 + 浅色背景卡,内部归因文本(嵌套引用折叠一层) |
  | code | 等宽字体深色卡(跟随暗色),横向可读、可复制 |
  | attachment | 文件附件行:图标 + 文件名 + 大小,点击下载/分享 |
  | fallback | 复杂 HTML(表格等)降级归因文本块 |
- **楼层 footer/操作**:长按楼层任意处弹出 `UIContextMenu`:回复、引用回复(M2)、复制文本、复制链接、收藏本帖、只看他(M3)、举报(M2)、评分(M2)、编辑(本人帖 M2)。回复按钮常驻楼层右下(M2 前)。
- **页导航**:导航栏 title「12/45」可点 → 菜单(上一页/下一页/跳页输入);列表尾部「下一页」按钮;阅读进度自动保存(离开页面时:页码+首个可见楼层 pid)与自动恢复(进入时跳转)。
- **顶部主楼区**:主楼(1 楼)上方展示帖子标题大字 + 作者信息卡。
- **状态**:每页独立 loading/错误重试;被删楼层显示「已被抹布」占位(黑名单/管理删除)。

### 4.4 GalleryViewController(图片画廊)
- 全屏黑底,`UIScrollView` 缩放 + `UIPageViewController` 横滑翻页;顶部页码指示与关闭/分享按钮;支持保存相册(需相册权限,在用户点击保存时请求)、复制图片链接。
- 转场:from 缩略图位置 zoom 过渡(尽量)。

### 4.5 LoginViewController
- `UITableView` form 样式:用户名、密码(secure)、安全提问(Picker 菜单,0=无提问~9)、提问答案;登录按钮(loading 态)。
- 错误以 alert 呈现服务端 messagestr;成功后 dismiss 并刷新用户态。
- 凭据写入 Keychain;「记住密码」默认开。

### 4.6 FavoritesViewController(收藏)
- 分页列表(50/页):标题/版块/收藏时间;swipe 左滑「移除收藏」(destructive,二次确认 alert);点击进帖。需登录,未登录展示引导空态。

### 4.7 HistoryViewController(历史)
- 本地 History 表(300 条上限):标题+最后浏览时间,支持搜索(标题 like);swipe 删除单条;工具栏「清空」(确认)。点击进帖并自动恢复进度。

### 4.8 BlacklistViewController / BlackWordViewController
- 黑名单行:用户名+备注+强度(主题/回复,隐藏/删除);添加(输入 uid/用户名)、编辑(备注+强度 segmented)、左滑删除。从网页导入(M3)。
- 屏蔽词行:词+强度(隐藏/删除);增删改同上。

### 4.9 SettingsViewController
- insetGrouped:
  - **图片**:仅 Wi-Fi 加载大图(开关)、清除图片缓存(行,显示缓存体积)
  - **阅读**:自动保存阅读进度(默认开)、自动恢复(默认开)
  - **关于**:版本、开源许可、帮助
- M3 增加:字号缩放、自定义 host、签名尾巴。

### 4.10 MessagesViewController(M1 占位)
- 未实现空态:「消息功能将在后续版本提供」+ 登录引导。M2 变为 Segmented:私信/通知。

## 5. 视觉规范

### 5.1 颜色
- 全部语义色:`.systemBackground / .secondarySystemGroupedBackground / .label / .secondaryLabel / .separator / .systemGroupedBackground` 等,深色模式零成本适配。
- **Accent(S1 Blue)**:`#4A78B8`(浅色)/ `#7BA3D9`(深色),Asset Catalog 提供 Any/Dark 变体,用于交互元素、accent 竖线、选中态。全局单一 accent。
- 图标色:语义色;破坏性操作 `.systemRed`。
- 楼层卡片区(引用/代码)用 `secondarySystemBackground`,暗色自动。

### 5.2 字体与 Dynamic Type
- 全量 `preferredFont(forTextStyle:)` + `adjustsFontForContentSizeCategory = true`。
- 帖子正文 `.body`,标题 `.headline`,辅助 `.footnote/.caption1`;代码块 `Menlo` 相对 `.footnote` 缩放(UIFontMetrics)。
- 帖子归因文本的字号/颜色 span(Discuz font 标签)映射为相对 `.body` 的比例,尊重系统字号设置。

### 5.3 图标与图片
- 系统 SF Symbols 优先(` star`, `arrowshape.turn.up.right`, `photo`, `doc`, `person.crop.circle.badge.xmark` 等)。
- 头像规则:`https://avatar.saraba1st.com/{uid 补零 9 位拆 3/2/2/2}_avatar_big.jpg`;默认占位 `person.crop.circle.fill`。

### 5.4 布局与手势
- 8pt 间距网格;列表 inset 16;触控目标 ≥44pt。
- 返回手势(edge swipe)全量保留,不遮挡;Tab 常驻不隐藏。
- 长按楼层 = 上下文菜单;下拉刷新 = 列表页;不支持音量键翻页(平台无此习惯,不移植)。

### 5.5 无障碍
- 所有图标按钮 `accessibilityLabel`;图片 cell 有描述(附件名/“图片 N”);VoiceOver 阅读顺序:楼层头→正文→操作。
- 支持 Bold Text / Increase Contrast(语义色天然支持);画廊缩放不受 Reduce Motion 约束(功能性),转场动画尊重之。

## 6. 与 S1-Next 的功能差异决策记录

| 决策 | S1-Next | S1 Goose | 理由 |
|---|---|---|---|
| 导航 | Drawer | 4 Tab | HIG 反对汉堡菜单 |
| 主题 | 9 主题+2 夜间 | 跟随系统+accent | HIG;维护成本 |
| 音量键翻页 | 支持 | 不做 | iOS 无此惯例 |
| 多账号 | 存储支持无切换 UI | 单账号+Keychain | 简化 |
| 本地缓存 | gzip KV 双库 | SQLiteData 单库(M3 备份) | 技术栈统一 |
| WebView 登录 | 备用通道 | M2 兜底 | 验证码场景需要 |
